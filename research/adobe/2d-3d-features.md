# Adobe Suite Relevant Features (2D Design for CAD)

## Illustrator
- Vector 2D design: paths, shapes, constraints-like tools.
- 3D capabilities: Extrude, revolve, inflate. Project Neo / Turntable for 2D-to-3D multi-view (editable vectors).
- AI: Generative textures, style transfer.
- Export: SVG, PDF, AI. Bridge to 3D via Substance or Dimension.

## Photoshop
- Raster editing, textures, maps for materials.
- Legacy 3D (removed in recent; use Substance 3D Viewer beta for 3D in 2D docs).
- AI Sensei: auto fill, object selection, optimization.
- Layers, smart objects for non-destructive.

## Relevance to CAD/CAM MVP
- 2D vector sketching/drafting excellence.
- Texture/material authoring for rendering/simulation.
- Seamless 2D-3D pipelines (extrude vectors to solids).
- AI-assisted design tools.

Source: Adobe product pages, help docs (2024-2026).

# Autodesk Fusion 360 Key Features (for CAD/CAM MVP)

## Core Modules
- **CAD**: Parametric, direct, surface, mesh, freeform modeling. Sketching, sheet metal, assemblies, joints/motion. 2D drawings associative from 3D.
- **CAM**: 2D/2.5D to 5-axis milling, turning, mill-turn, laser/waterjet/plasma. Adaptive clearing, probing, inspection. Post-processors. Additive manufacturing.
- **Simulation (CAE)**: Static/thermal stress, modal frequency, buckling, event sim, shape optimization. Cloud FEA. Generative design.
- **Electronics**: PCB design, schematics, integrated with mechanical.
- **Rendering**: Photorealistic with materials, lighting.
- **Collaboration**: Cloud, version control, user management, data management.

## Export Formats
STEP, IGES, STL, DWG, DXF, OBJ, F3D, etc. (50+ translators).

## Strengths to Emulate
Integrated CAD/CAM/CAE in one tool. Parametric history. Generative design. Real-time collaboration. Machine simulation.

Source: Autodesk product pages, feature lists (2026).

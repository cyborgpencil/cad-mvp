# FreeCAD Key Features

## Architecture
- Open-source (LGPL), C++/Python. Modular workbenches.
- Geometry kernel: OpenCASCADE (OCCT) - B-Rep, NURBS, solids, booleans, fillets, STEP/IGES native.

## Core Features
- **Parametric modeling**: History tree, property-driven. Sketcher with constraints.
- **Part Design**: Pads, pockets, fillets, patterns, booleans.
- **Part**: CSG, primitives, Boolean ops.
- **Assembly**: Built-in solver (1.0+), joints, motion.
- **TechDraw**: 2D technical drawings, views, dimensions, SVG/PDF export.
- **CAM**: Toolpaths (face, pocket, contour, drill), tool library, post-processors, G-code, simulation.
- **FEM**: Finite element analysis (stress, etc.), meshing.
- **BIM**: Architectural modeling, IFC.
- **Mesh**: Processing for 3D printing.
- **Python API**: Full scripting, macros, automation.

## Formats
Import/export: STEP, IGES, STL, 3MF, DXF, SVG, OBJ, DAE, IFC, etc. Native FCStd.

## Strengths to Emulate
Free/open, extensible via Python/workbenches. Full parametric B-Rep. Integrated CAM/FEM. High precision units.

# Tooling Priority Prompt (Reusable)

Use this when starting or planning work that can be done with Grok Build, Cursor, or Grok Bots.

## Instructions

Follow the tooling-priority skill:
- Prefer Grok Build for large autonomous or multi-module tasks (use plan mode first).
- Use Cursor for interactive refinement, debugging, and fine-grained multi-file edits.
- Assign Grok Bots only to recurring research, documentation routines, or coordination that does not block coding.
- Never invent missing requirements. Review diffs that affect core logic or validation.
- Keep work incremental and testable. Re-scope failed attempts back to Grok Build.

Load project rules (AGENTS.md or equivalent) and current requirements before planning.
